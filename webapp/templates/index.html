🤖 What even is a Persona Prompt?

A persona prompt is a special system message you put at the start of a conversation with an LLM. It tells the AI how to behave: its personality, speaking style, background, and worldview. Done right, the AI fully embodies the character — answering questions exactly as that person would, without breaking immersion. This game exploits exactly that power to create a guessing game!

🔑 Prompting Tips for This Game

  • → Ask yes/no questions first to narrow down era, world, and genre.
  • → Try "Are you human?", "Are you alive?", "Do you have supernatural powers?"
  • → Ask about relationships: "Do you have a nemesis?", "Do you have a family?"
  • → Reference time period: "Did you live before the 20th century?"
  • → Ask about medium: "Am I more likely to find your story in a book or on screen?"
